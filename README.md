# 魔法の球

線を描けば、それが魔球になる。ピッチャーの後ろから線を描いて魔球を登録し、合言葉で投げ合う3Dブラウザ野球ゲーム（なすびのお庭）。

遊ぶ: https://nasubi-no-oniwa.github.io/mahou-no-tama/

- 線はピッチャーの後ろから描く。「上から見る」「横から見る」を押すと、まずストライクゾーンのどこに投げるかを決め、その向きから見た曲がり方・高さを描き足せる（今の魔球に重ね、手とゴールに合わせて自動で整える）
- 球速は線にそって100km/h固定。線の長さの上限は50m（まっすぐの約3倍）。ストライクゾーンで止めない線は受けつけない
- 合言葉は8文字（0・O・1・I・L は使わない）。`?code=合言葉` のリンクで、その魔球の打席に入れる
- 打席は3ストライクまで。ヒット以上で打者の勝ち。1人1魔球につき最初の打席だけ記録
- ランキングは「奪三振（挑戦 − 打たれた）」の多い順
- データは Firebase（furoya-no-onna プロジェクト）の `mahou`。ルールは furoya-no-onna リポジトリの `database.rules.json` に入っていて、上げると自動で反映される。`database.rules.mahou.json` は `mahou` の部分の写し
